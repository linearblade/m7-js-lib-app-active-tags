# Examples

All examples in this tree are currently spec'd for the **ActiveTags standalone 1.0** runtime.

Default runtime target:

- `/vendor/m7-js-lib-active-tags/dist/activeTags.standalone.v1.0.min.js`

Runtime override options used by the example loaders:

- `?runtime=dist` -> versioned 1.0 minified bundle (default)
- `?runtime=dev` -> source standalone prebundle for local development
